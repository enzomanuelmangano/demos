# Demos on Exact

The Demos launcher and its 109 animations, rebuilt on Exact:
the UI and state are written in Contract, the heavy per-frame work (Skia-style drawing, shaders,
physics) runs in Rust on wgpu, and the few things that must be native UIKit live in Swift.

## Layout

| Path | What lives there |
| --- | --- |
| `app.contract`, `app.ts` | The app: routing, the launcher, the demo screen. |
| `home/` | Launcher screens: the springboard, the demo screen shell, the atlas. |
| `demos/<slug>/<slug>.contract` | One demo's UI, state and gestures. |
| `demos/index.contract` | Registers every demo by slug. |
| `demos.contract` | The launcher's list (generated by `tools/gen-demos.ts`). |
| `gpu/src/<slug>.rs` | A demo's GPU surface, when it draws per frame. `gpu/shaders/` holds its WGSL. |
| `modules/apple/` | Native views: glass buttons, sheets, alerts, tab bars, haptics. |
| `packages/` | Helper crates the demos rely on: `motion`, `gestures`, `pressto`, `draw2d`, `noise`. |
| `assets/` | Icons, images, fonts, audio. |

A demo with a GPU surface is split in two on purpose: the Contract file owns layout and input,
the Rust file owns the pixels. They meet by the surface's name.

## Run

```sh
bun install
bun exact.mjs web --port 5341          # dev server with hot reload
bun exact.mjs mac --run --url http://localhost:5341
bun exact.mjs phone <udid> --run --url http://<your-lan-ip>:5341
```

`bun exact.mjs help` lists every verb. `bun tools/gen-demos.ts` rebuilds the launcher's list from
the original React Native app's registry.

## Lint

`tools/lint.sh all` runs the Contract linter (polish and performance rules, with a baseline of accepted debt), the Rust format
and clippy gate, the TypeScript check of the Bun tooling and the generated-files check; CI runs the part that needs no Exact
checkout. What each check does, how to add a rule and how the baseline works: [LINT.md](LINT.md).

## Adding a demo

1. Add `demos/<slug>/<slug>.contract` with a component that takes `env: DemoEnv`.
2. Register it in `demos/index.contract` and the launcher list.
3. If it needs per-frame drawing, add `gpu/src/<slug>.rs` and expose its `surface()`.

See `.claude/skills/port-demo/SKILL.md` for the full routine.
