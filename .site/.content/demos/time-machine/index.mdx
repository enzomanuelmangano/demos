This demo is definitely far from perfect, but I've had this idea in mind for a
while and wanted to try it out.

The goal is to create a timeline of events with an intuitive way to navigate through them. The initial idea was to use a "Shake Gesture" to trigger the time machine, but it was hard to record the demo 😅.
It should be very easy to add it, though it won't work on Expo Go (and I really want to have all this demos on Expo Go 😅).

It's built on top of two of my old demos:

- [Story List](/demos/story-list)
- [Drag and Sort](/demos/drag-to-sort)

The Shader idea came from this amazing tutorial created by Daniel Friyia: [Introduction to Game Development with Expo, Skia and Reanimated](https://youtu.be/Af2-OT9mE14)
