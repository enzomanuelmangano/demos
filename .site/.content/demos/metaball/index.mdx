An interactive metaball effect with gradient colors and touch gestures.

## What's This About?

This component creates an engaging metaball visualization where two circular shapes blend together with a fluid-like effect. Users can interact with both circles through touch gestures, creating dynamic blending animations. The implementation features a gradient color effect and blur transformations to achieve a smooth, liquid-like appearance that responds naturally to user interaction.

## Technical Implementation

The component uses:

- Skia for rendering
- Gesture handling
- Path manipulation
- Color matrices
- Gradient effects
