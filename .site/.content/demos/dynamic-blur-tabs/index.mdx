A bottom tab navigator with dynamic blur effects based on scroll position. Built with React Navigation.

## What's This About?

This component creates a tab bar that:

- Shows blur effects while scrolling
- Uses React Navigation for routing
- Supports multiple screens
- Freezes inactive screens

## Technical Implementation

The component uses:

- React Navigation's bottom tabs
- Custom tab bar component
- Screen freezing for performance
- Dynamic screen mapping
- Gradient backgrounds

## Usage

```tsx
// Basic usage
<DynamicBlurTabs />;

// Component structure
const BottomTab = createBottomTabNavigator();

<BottomTab.Navigator
  initialRouteName="home"
  screenOptions={{
    headerShown: false,
  }}
  tabBar={(props) => <BottomTabBar {...props} />}
>
  {screens.map((screen) => (
    <BottomTab.Screen
      key={screen.name}
      name={screen.name}
      component={screen.component}
      options={{ freezeOnBlur: true }}
    />
  ))}
</BottomTab.Navigator>;
```
