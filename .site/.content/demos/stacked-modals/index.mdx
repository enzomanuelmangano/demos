This is the first exclusive demo I launch on Demos 🎉

Even though this is actually a modal, you can see this animation as the natural evolution of the good old Toast:

- [v0. Toast Manager with Reanimated and Gesture Handler 🍞](/demos/toast/)
- [v1. Stacked Action Tray](/demos/stacked-bottom-sheet/)
- [v2. Clerk Toast](/demos/clerk-toast/)
- v3. Stacked Modals: this one :)

I would say that this animation is a combination of two ingredients:

- Layout Animations (as always)
- Extensive optimization through heavy memoization

The animation itself is relatively simple, but the real challenge lies in supporting potentially infinite modals. While this scenario is rare in real-world applications, it’s a fun challenge to tackle nonetheless.
